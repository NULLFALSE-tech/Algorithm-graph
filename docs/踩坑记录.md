# 踩坑记录

> 谁踩到谁记，一条一行。**记这个的唯一目的：让后面的人少花时间。**
> 先遣员（P4 张超明）第一个走完全流程，这里前 5 条都是他记的。

## 格式

| 现象（你看到什么） | 原因 | 怎么解决 | 花了多久 |
|---|---|---|---|

现象要写**你能截图的那句话**，比如 `Permission denied (publickey)`，不要写「推不上去」。

## 记录

| 现象 | 原因 | 怎么解决 | 花了多久 |
|---|---|---|---|
| `remote: Support for password authentication was removed` | GitHub 早就不让用密码推了 | 去 Settings → Developer settings → Personal access tokens 生成一个，**当密码用** | 15 分钟 |
| `git status` 里中文文件名显示成 `\344\270\255\346\226\207` | git 默认转义非 ASCII | `git config core.quotepath false` | 2 分钟 |
| 页面打开一片空白，浏览器报 `Failed to load resource: 404`（图片） | 图片路由前缀是 `/img/`，键盘敲成了 `/imgs/` | 看 `eg/app.py` 的路由表，前缀是 `/img/`；路径还要带 `docs/chapter_xxx/xxx.assets/` 这一层 | 8 分钟 |
| `python` 不是内部或外部命令 | 装 Python 时没勾 Add to PATH | 重装并勾选，或用 `py` 代替 `python` | 5 分钟 |
| `verify.py` 报某条算法 FAIL | 改坏了 `data/algos.json` | `git diff data/algos.json` 看自己改了哪行，改回去；搞不定就 `git checkout -- data/algos.json` 重来 | 3 分钟 |
