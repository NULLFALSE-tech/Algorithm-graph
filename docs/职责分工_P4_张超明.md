## 一、任务 A：README 加「主要功能」

### 加在哪

`README.md` 的「## 一、项目简介」末尾，新增一个 **`### 主要功能`** 小节。

> ⚠️ **标题不要带编号**（就写 `### 主要功能`，不要写 `### 1.2`，也不要新开 `## 二、主要功能`）。原因：
> ① 「一、项目简介」下面现在**一个子标题都没有**，凭空冒出 `1.2` 很怪；
> ② 新开 `## 二、主要功能` 的话，「二、快速开始」到「九、许可」全部要顺延，
> 而 README 里还有「见第八、九节」这类引用要跟着改——一个编号能连累三处，不值得。

### 写哪 6 条（逐条点过再写，点不到就删掉那条）

| # | 功能 | 怎么验证 |
|---|---|---|
| 1 | 分层图谱总览：首页把 **33 个主干算法**按 5 层铺开成有向图，层内层间都有依赖连线；其余算法从「全部源码」入口看（共 **76** 份） | 打开首页数方块，应是 33 个 |
| 2 | 关键词检索：算法中文名 / 英文名 / 简介 / 源文件名 / 章节名，任一命中即出，大小写不敏感 | 搜「二分」应出 5 条、「binary」9 条、「排序」9 条 |
| 3 | 算法详情页：一句话简介 + 原理图 + 逐行着色的 C 源码 + 编译运行结果 | 随便点 3 个算法看完 |
| 4 | 依赖连线：图谱上 32 条曲线表示「建议的学习先后」，跨层的从左指向右 | 看首页底下那行图例 |
| 5 | 详情页翻页：按层级顺序串成「← 上一个 / 下一个 →」，不用回首页 | 连点 5 下，看层级 |
| 6 | 零依赖启动：只用 Python 标准库，`python app.py` 即可，不装任何包 | 新开一个终端跑一遍 |

### 三条实测过的坑，别踩

- **第 1 条的 33 不是 76**。图谱上**只画带精讲的 33 个主干节点**，76 是全量源码。写错这个数字，现场一数就翻车。
- **第 4 条：依赖只体现在首页图谱的连线上**。详情页**没有**「跳到它依赖的算法」这种链接——详情页里只有上一个/下一个。别把没有的写成有。
- **第 5 条：详情页底部有一句总的「代码来源：hello-algo 仓库 codes/c/ 目录」**，但**没有**逐条显示「这个算法来自哪个文件第几行」。同样别夸大。
