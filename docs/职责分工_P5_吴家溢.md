### 任务群 A · 分镜表

```
需要为一个课程项目排一张 6 分半的演示视频分镜表。

项目：把《数据结构》76 条算法（其中 33 条带精讲）的讲解和 C 源码，做成按 5 层组织、
带依赖连线的本地网页知识图谱。Python 标准库实现，零第三方依赖，服务端渲染。
团队 6 人，使用 Git 分支与 PR 协作，有一次真实的合并冲突。

评分权重：文档规范 20%、Git 协作 30%、大模型编程 25%、程序演示 25%。

要求：
- 按时间码排，总长不超过 6 分 30 秒
- 每一段标明「画面、讲什么、对应哪一项评分」
- Git 协作与大模型编程合计 55 分，必须在画面中被明确展示，不能只用口述带过
- 先只给时间轴和每段一句话，不要写口播稿

```

产出核对：时间码连续无断档，末段时间码不超过 6:30，四类评分点在表中均出现。

### 任务群 B · 口播稿

```
把下面这张分镜表写成可以直接念的中文口语稿，每段不超过 150 字。

（粘贴分镜表）

要求：
- 口语，像给同学讲解，不使用书面语
```

口语化标准参考：

| 书面表述（不采用） | 口语表述（采用） |
|---|---|
| 本项目采用分层架构设计，有效提升了系统的可维护性 | 我们把它拆成五个文件，每个只管一件事。谁改坏了，跑一下自检就知道是哪个环节 |

### 任务群 D · 提交规范巡检

本任务以命令输出为依据，不写主观评价。

先取数，五条命令均为只读：

```bash
cd /d/CODE/Algorithm-graph
```

```bash
git shortlog -sn --all
```

```bash
git log --pretty=format:'%ad' --date=format:'%Y-%m-%d %H:%M' | sort | uniq -c
```

```bash
git log --pretty=format:'%h %an %ad %s' --date=short -40
```

```bash
git branch -a
```

```bash
git log --merges --oneline
```

再按下表逐项判定，结果写入报告：

| 检查项 | 合格标准 | 判定依据 |
|---|---|---|
| 提交说明格式 | 形如 `类型(范围): 一句话`；纯文档类可省略范围写成 `docs: 一句话`；不出现「update」「修改」「1」这类裸词 | 命令 3 的输出 |
| 作者名 | 中文真名：邓宇轩、王瑞、郭子琪、张超明、吴家溢、焦明远 | 命令 1、3 的输出 |
| 提交时间 | 至少跨越 5 个不同日期 | 命令 2 的输出 |
| 作者分布 | 六人均有提交，组长占比不超过总量 60% | 命令 1 的输出 |
| 分支隔离 | 存在 5 条以上 `docs/*`、`feat/*` 分支 | 命令 4 的输出 |
| 冲突记录 | 至少 1 个 merge commit 由人工解决冲突产生 | 命令 5 的输出与 PR 描述 |
| 禁止项 | 无强制推送，无 `reset --hard` 抹除历史 | 命令 5 是否出现历史断裂 |

巡检开始前的已知现状，如实记录即可，不作修饰：

| 项目 | 当前实测 |
|---|---|
| 提交总数 | 35 |
| 不同分钟数 | 4，其中 31 个提交落在同一分钟 |
| 作者分布 | 邓宇轩 30，其余五人合计 5，组长占比约 86% |
| 分支总数 | 22（含远程） |
| merge 节点 | 10 |

因此「提交时间」与「作者分布」两项在巡检时大概率判定为不合格。报告按实际情况书写，格式为「当前不达标，原因为何，随 11/19–11/26 各人分日提交预期改善」。不修改数字，不修改 Git 历史。

## 三、AI 使用禁区

| 禁止事项 | 具体说明 | 原因 |
|---|---|---|
| 让 AI 编造演示步骤 | 每一段画面都必须是能真实执行的操作 | 录制时按稿操作会卡住，现场效果差于不录 |
| 让 AI 改写 Git 历史或给出改写命令 | rebase、reset、强制推送一类命令一律不执行 | 一次误操作可毁掉全组仓库且不可恢复 |
| 让 AI 直接给出巡检判定 | 判定依据只能是命令输出 | AI 无法读取仓库状态，其判断必然失真 |
| 让 AI 把不确定的表述写成断言 | 不写「我们认为」「大概是」「应该是」 | 演示稿需要确定表述 |
| 让 AI 生成超过 6 分 30 秒的脚本 | 时长按评分权重分配，不按字数堆叠 | 评阅时长有限，超时会压缩实操段 |
| 让 AI 处理视频文件本身 | 脚本中不涉及 mp4 的提交与转码 | 视频由组长录制并单独提交 |
